## 📦 Installation

1. **Install PyTorch with GPU Support (Recommended):**
   ```bash
   pip3 install torch torchvision torchaudio --index-url [https://download.pytorch.org/whl/cu121](https://download.pytorch.org/whl/cu121)

Install the rest of the requirements:

Bash

pip install -r requirements.txt



##important note: If you have an NVIDIA GPU and want to leverage it for faster training and inference, make sure to install the CUDA-enabled version of PyTorch. The above command installs the version compatible with CUDA 12.1. If you don't have a compatible GPU or prefer to use CPU, simply run:
   ```bash
   pip3 install torch torchvision torchaudio
